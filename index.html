Montefiore Square Redesign

Safer & Better-Lit Pedestrian Plaza

Project Overview

This project reimagines Montefiore Square as a safer, more accessible, and visually engaging pedestrian plaza. The redesign focuses on lighting, greenery, and spatial clarity to improve user experience.

Design Goals

  • Improve pedestrian safety
  • Enhance lighting and visibility
  • Create a welcoming public space
